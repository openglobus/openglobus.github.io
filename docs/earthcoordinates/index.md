# EarthCoordinates

<SourceLink href="/source/control/earthcoordinates-ts/#L44" label="EarthCoordinates.ts:44" />

Control displays mouse or screen center Earth coordinates.

---

## Constructor

<Signature code="new EarthCoordinates(): EarthCoordinates" />

**Parameters**

- `options.center` (Boolean, optional) — Earth coordinates by screen center otherwise mouse pointer. False is default.
- `options.type` (Boolean, optional) — Coordinates shown: 0 - is decimal degrees, 1 - degrees, 2 - mercator geodetic coordinates.
